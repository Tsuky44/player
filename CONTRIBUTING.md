# Contribuer à Onyx

Merci de ton intérêt pour Onyx. Le projet est en beta : les retours de test comptent autant que le code.

## Remonter un bug ou proposer une idée

Ouvre une [issue](https://github.com/Tsuky44/player/issues). Pour un bug, indique :

- la plateforme et la version de l'app (Réglages → À propos) ;
- la version du serveur et la façon dont il est installé (Docker, NAS, autre) ;
- les étapes pour reproduire, et ce que tu attendais ;
- pour un problème de lecture : le conteneur et les codecs du fichier.

## Proposer une pull request

1. Pour autre chose qu'une petite correction, ouvre d'abord une issue pour en discuter : ça évite de travailler sur quelque chose qui ne sera pas intégré.
2. Garde la PR ciblée : un sujet par PR.
3. Suis les conventions du code existant, et assure-toi que la CI passe.
4. Accepte l'[accord de contribution](CLA.md) en cochant la case dans la description de la PR.

## Pourquoi un accord de contribution ?

Onyx est en source disponible, sous licence [PolyForm Noncommercial](LICENSE), et une offre payante financera son développement. L'accord permet à l'auteur de publier l'application sur les stores et de la commercialiser avec le code des contributeurs. Tu restes propriétaire de ce que tu écris.
